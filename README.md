Консольное приложение, имитирующее работу простейшей библиотечной системы. Проект демонстрирует основы объектно-ориентированного программирования на C++: инкапсуляцию, композицию классов, разделение интерфейса и реализации.

Приложение позволяет:
1.  Создавать объекты книг (`Book`), содержащие название, автора и ISBN.
2.  Создавать объект библиотеки (`Library`), который может хранить в себе коллекцию книг.
3.  Добавлять книги в библиотеку.
4.  Выводить список всех книг в библиотеке.
5.  Искать книгу по её ISBN.
6.  Менять статус книги (выдана/доступна) через методы `borrow()` и `returnBook()`.
